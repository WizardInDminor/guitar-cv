# DAC Output — CV Generation

## Overview

CV output is generated by the MCP4922 dual 12-bit SPI DAC. The MCU converts a detected MIDI note number into a DAC count using the 1V/oct convention, then transmits the 16-bit command word over SPI2.

See also: [CV Math — 1V/oct](../concepts/cv-math.md), [MCP4922 Command Word](../reference/mcp4922-command-word.md), [MCP4922 Wiring (datasheet-verified)](../hardware/wiring-mcp4922.md)

---

## Wiring

Pin numbers below are taken directly from the Microchip MCP4922 datasheet (14-pin PDIP,
Table 3-1). See [MCP4922 Wiring](../hardware/wiring-mcp4922.md) for the full verified
diagram, header pin mapping, and datasheet sources.

| MCP4922 Pin | Signal | Connection |
|---|---|---|
| 1 — VDD | Power | 3.3V |
| 3 — CS̄ | Chip select | PB12 (GPIO, idle high) |
| 4 — SCK | SPI clock | PB13 (SPI2_SCK, AF5) |
| 5 — SDI | SPI data in | PB15 (SPI2_MOSI, AF5) |
| 8 — LDAC̄ | Latch DAC | GND (tied low) |
| 9 — SHDN̄ | Hardware enable | **3.3V** (must be high or outputs are disabled) |
| 12 — VSS | Ground | GND |
| 13 — VREFA | Channel A reference | 3.3V |
| 14 — VOUTA | CV output | → scope / Eurorack |

![MCP4922 Pinout](../img/mcp4922-pinout.png) 
![MCP4922-pin-function](../img/mcp4922-pin-function.png)
 
LDAC (pin 8) is tied permanently low so the output updates on the rising edge of CS. SHDN
(pin 9) is the hardware shutdown input — it must be tied high (active-low), otherwise both
DAC outputs stay disabled regardless of the `/SHDN` command-word bit. This is the correct
configuration for single-channel real-time CV output.

## Note to DAC Conversion

Implemented and unit-tested in `src/cv.c` / `include/cv.h`
(tests: `test/test_cv.c`, run with `make test`). Rounds to nearest (max 0.5 LSB error):

```c
uint16_t note_to_dac(uint8_t midi_note) {
    float semitones = (float)((int)midi_note - CV_REF_NOTE);  // C4 = 60 = 0V
    float voltage   = semitones / CV_SEMIS_OCT;
    float count     = (voltage / CV_VREF) * CV_DAC_COUNTS;     // CV_VREF = 3.3f

    if (count < 0.0f) return 0;
    count += 0.5f;                                             // round to nearest
    if (count > (float)CV_DAC_MAX) return CV_DAC_MAX;
    return (uint16_t)count;
}
```

## MCP4922 Write

The command-word packing is the pure, unit-tested `mcp4922_command()`
(`src/mcp4922.c`); the SPI transmit is added in the bench bring-up session:

```c
uint16_t mcp4922_command(uint8_t channel, uint16_t value) {
    uint16_t cmd = 0;
    cmd |= (channel & 0x1) << 15;  // channel select
    cmd |= (1 << 13);               // gain 1x
    cmd |= (1 << 12);               // active (not shutdown)
    cmd |= (value & 0x0FFF);        // 12-bit data
    return cmd;
}

void mcp4922_write(uint8_t channel, uint16_t value) {
    spi2_write16(mcp4922_command(channel, value));
}
```

## Calibration

!!! note "Calibration Required"
    The 3.3V rail on the DISC1 is not exactly 3.3V. Initial measurements will be close but not exact. Calibration involves measuring actual Vref and adjusting the constant in `note_to_dac()`. This is deferred to a dedicated calibration session.

## Reference Voltage Table

Expected output voltages with 3.3V reference:

| Note | MIDI | Semitones from C4 | Target Voltage | DAC Count |
|---|---|---|---|---|
| C4 (ref) | 60 | 0 | 0.000V | 0 |
| C#4 | 61 | 1 | 0.083V | 103 |
| A4 | 69 | 9 | 0.750V | 931 |
| C5 | 72 | 12 | 1.000V | 1241 |
| C6 | 84 | 24 | 2.000V | 2482 |

!!! tip "First Bench Test"
    Send DAC count 1241 and verify 1.000V on the oscilloscope. One volt represents exactly one octave above reference — the cleanest possible first measurement.
